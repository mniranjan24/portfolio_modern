# Alex Morgan — The Portfolio Series

A buildless, cinematic portfolio implemented with vanilla HTML, CSS, JavaScript, GSAP 3, and ScrollTrigger.

## Run locally

Serve the folder with any static server, for example:

```powershell
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Structure

- `index.html` — document structure and CDN scripts
- `css/styles.css` — visual system, responsive layouts, motion fallbacks
- `js/data.js` — placeholder portfolio content
- `js/app.js` — rendering, profiles, modals, GSAP timelines, ScrollTrigger

Replace the placeholder URLs, copy, and profile content in `js/data.js`. No install or build step is required.
